# 우리의 건강한 하루 — 부부 건강관리 PWA

갤럭시(Chrome)와 아이폰(Safari, iOS 16.4+) 홈 화면 설치를 지원하는 MVP입니다.

## 기능
- 남편/아내 개인별 식단 및 요일별 운동표
- 일일 일정 체크, 업무·생활 복기
- 체중·허리 기록 (브라우저 localStorage, 기기별 저장)
- 알림 시간 조정, 웹 푸시 구독 및 테스트 (서버 구성 시 백그라운드 푸시)
- PWA 설치, 기본 오프라인 캐시

## 실행
Node.js 20 이상이 필요합니다.

```bash
npm install
npm run keys
```

`npm run keys`에서 출력한 키를 환경변수로 설정하세요.

```bash
export VAPID_PUBLIC_KEY='출력된 public key'
export VAPID_PRIVATE_KEY='출력된 private key'
export VAPID_SUBJECT='mailto:you@example.com'
npm start
```

브라우저에서 `http://localhost:3000`으로 확인할 수 있습니다. **실제 휴대폰 설치 및 푸시는 HTTPS 공개 배포가 필요합니다.** Render/Railway/Fly.io/VPS 등 Node 서버를 실행할 수 있는 호스팅에 배포하고 환경변수를 설정하세요. 서버는 푸시 발송을 위해 계속 가동되어야 합니다. 무료 서버의 슬립 정책을 확인하세요.

- 남편 갤럭시: Chrome으로 HTTPS 주소 열기 → 메뉴 → 홈 화면에 추가/앱 설치 → 앱 실행 → 알림 탭 → 알림 권한 허용 및 저장.
- 아내 아이폰: Safari로 HTTPS 주소 열기 → 공유 → 홈 화면에 추가 → 홈 화면에서 앱 실행 → 알림 탭 → 알림 권한 허용 및 저장. iOS 16.4 이상 필요.
- 각자 기기에서 자신의 프로필을 선택하세요. 기록은 서로 자동 동기화되지 않습니다.
- QR을 만들려면 배포 후 실제 HTTPS 주소를 QR로 변환하세요. 현재 패키지에는 공개 URL이 없어 배포용 QR이 포함되지 않습니다.

## 중요한 한계
- 실제 백그라운드 푸시는 서버와 VAPID 환경변수를 설정한 뒤에만 작동합니다. 단순히 ZIP을 열거나 로컬 HTML 파일을 실행해서는 작동하지 않습니다.
- 서버의 `subscriptions.json`은 프로토타입용이며, 실제 서비스에서는 DB, 인증, 암호화, 운영 모니터링 및 구독 삭제 절차가 필요합니다.
- 현재 서버는 단일 기기별 익명 ID로 구독을 관리합니다. 동일 브라우저에서 프로필을 변경하면 마지막 설정이 적용됩니다. 부부는 각자 기기에서 사용하세요.
- 서버가 재시작되어도 구독은 DATA_PATH 파일에 남지만, 파일시스템이 일시적인 호스팅이면 데이터가 유실됩니다. 영구 디스크를 연결하세요.
- 알림 발송은 서버가 매분 확인하는 방식입니다. 서버 정지·네트워크·운영체제 절전 정책에 따라 지연/미전송이 발생할 수 있습니다.
- 서버에 체중 기록은 전송되지 않고, 기기에만 저장됩니다. 기기 데이터 삭제 시 기록도 사라집니다. 기록 탭에서 JSON 백업을 받으세요.
- 의학적 판단이나 체중 감량을 보장하는 앱이 아닙니다. 병원 환자용으로 확장할 때는 의료정보 처리와 개인정보 보호, 동의·접근통제 설계가 필요합니다.
